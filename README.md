### Research

**Minimum-edit decomposition of DFAs**
Research intern at the [Tehran Institute for Advanced Studies (TeIAS)](https://teias.institute/), advised by [Prof. Hossein Hojjat](https://scholar.google.com/citations?user=hkfVNCMAAAAJ&hl=en) and [Prof. Mahboubeh Samadi](https://teias.institute/samadi-talk202410/), since Spring 2026.
Some DFAs cannot be split into smaller DFAs that together recognize the same language. We use SAT-based methods to find the fewest changes that make such an automaton decomposable.

> S. Samadi, M. Samadi, H. Hojjat. *Minimum-Edit Decomposition of Deterministic Finite Automata.* Manuscript in preparation.

**A meta model checker for Rebeca**
Research assistant at the University of Tehran, advised by [Prof. Fatemeh Ghassemi](https://profile.ut.ac.ir/en/~fghassemi), since Fall 2026.
Rebeca is an actor-based modeling language with many extensions, each with its own model checker. This project aims to support them in a single tool.
