## Hi, I'm Sadegh

I study Computer Engineering at the [University of Tehran](https://ut.ac.ir/en). I'm mostly interested in automata theory and formal verification.

At the moment I'm working on two research projects. In one, we look for the smallest set of changes that lets a DFA be split into smaller automata, and we use SAT solvers to find it. The other is a model checker for Rebeca, an actor-based modeling language, that aims to handle its many extensions in one place.

I got into computer science through the Iranian National Olympiad in Informatics (INOI), and I still enjoy algorithmic problems, both solving them and designing them for courses and contests. I also build small tools when I need them, like a [Leitner box app](https://github.com/imSaDy/leitner-box) I use to study vocabulary for the TOEFL, and an [AI player for Othello](https://github.com/imSaDy/Othello).
